A dark aesthetic anime media gallery built with HTML, CSS, and JavaScript.

## Setup Instructions

1. Clone or download this repository.
2. Ensure your media files are placed inside the `assets/` directory with the following filenames:
   - `kkumar7510_pindown.io_1791021917.jpg`
   - `Trending 4K Amoled Walpaper For PC.jpg`
   - `Shinigami_00_pindown.io_1789183399.mp4`
   - `WorkerrF90_pindown.io_1789141609.mp4`
3. Open `index.html` in any browser or host directly via GitHub Pages.
